## 实施原则

- 基于当前工作区实现补缺口，保留已有暂存、未暂存和新文件。
- 仅调整移动端表现，复用 CSS、Svelte 和现有动画工具，不安装依赖。
- 保留播放、载入、下载、错误状态及键盘操作；减少动态效果时取消位移、旋转和形态动画。
- 微反馈约 160–240ms，主要转场约 300–400ms；快速重复操作能够中断旧动画。
- 不添加持续流动背景或封面唱片化，不改播放链路、主题配置和原生端。
