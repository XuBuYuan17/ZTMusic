# Android 真机手工测试记录

测试日期：2026-10-02。设备型号 2211133C，系统报告 Android 17 / API 37；测试包 com.zheting.music.androidtest，版本 1.4.1。

通过 ADB 操作系统返回键、触屏操作及 WebView 调试检查实际安装的 APK。手机仍使用此前云端构建，未包含本轮本地修复。未删除歌单、清空队列、退出登录或更换壁纸。

| 项目 | 结果与复现 |
| --- | --- |
| 明暗主题 | 切换后的静态颜色正常。导航菜单的主题切换使用整页 View Transition，并叠加颜色过渡；用户报告闪烁，动态视觉改善需新 APK 复测。 |
| 弹层系统返回 | 设置 → 语言 → 按 Android 返回键，应用退到后台，语言弹层未关闭。已确认。 |
| 页面系统返回 | 搜索页打开键盘，首次返回正常收起键盘；再次返回将应用退到后台，没有返回应用上一页。已确认。 |
| 首页与设置 | 当前设备宽度 392 CSS px，页面无横向溢出。 |
| 队列 | 弹层尺寸在视口内，歌曲标题截断正常，界面关闭按钮正常。下拉手柄测试未得到可靠结论，不计为通过或故障。 |
| 播放器 | 打开／收起、封面切换歌词、更多操作菜单正常；未检查整首播放完成、锁屏或长时间后台。 |
| 搜索输入法 | 原生截图中输入法打开，底部导航仍露在输入法下方，播放条被遮挡；WebView 的 innerHeight 和 visualViewport.height 仍报告 872，键盘布局需继续检查。 |
| 媒体通知 | 已知未实现原生 MediaSessionService，不作为本轮 UI 回归故障。 |
| 听歌统计 | 用户反馈 Android 没有累计；代码确认统计初始化、创建会话、采样和定时保存均跳过移动端。本轮移除这些限制，新增移动端采样、暂停、跳转、保存重试回归测试；移动尺寸浏览器真实 IndexedDB 写入及刷新读取通过。旧版本漏记的时长无法准确补回。 |

本轮修复移动端主题切换、Android 返回键接入和听歌统计。主题变化短暂关闭 CSS 过渡；返回优先关闭最上层弹窗、导航抽屉及播放器，否则走已有路由返回。首页无弹层时注销返回监听，保留系统默认行为。

键盘布局、下拉手柄、长时间后台播放及耳机／蓝牙尚未完成验证。新 APK 安装后必须重测上述两项修复，本地构建或浏览器检查不代表真机验证通过。
