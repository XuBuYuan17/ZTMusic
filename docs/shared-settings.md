# PC 与移动端共用分类设置页

两端共用 `src/lib/pages/Settings.svelte` 和分类定义，沿用现有 `useSettings()`、设置键名及持久化方式。PC 和移动端都先显示分类首页，点击后进入子页；每个子页的第一项为“返回设置分类”。

分类保持外观、播放与歌词、音源管理、通用、数据与账号、高级、关于；Android 原生运行时另显示 Android 功能。窗口布局与运行平台分别判断，Android 横屏仍保留原生功能。PC 保留“主页”默认启动页选项。

分类、分组、标题/说明的翻译键、摘要规则及普通字段集中在 `src/lib/settings/definitions.ts`。普通开关与选择项由公共循环渲染；默认值、合法选项和数值边界也由存储校验读取。主题、语言、音质保留业务模块适配，复杂的音源、壁纸和 Android 功能继续使用专用内容。

增加普通持久化字段时，在定义中声明分类、类型、默认值、文案和选项；页面与校验自动接入。需要触发歌词等消费者刷新时，在字段定义中声明现有事件。新增功能的实际业务行为仍由对应模块实现。

音质顺序、标签和选项共用 `src/lib/player/quality.ts`，不再从设置状态模块导入常量。原有持久化键、默认值、未知键兼容行为及迁移版本 4 保持不变；主题和语言由各自模块管理，不新增到设置迁移的默认写入列表。

启动页执行与设置页展示共用可见选项规则：移动端保存“资料库”后会实际进入资料库；旧的“主页”偏好在移动布局下仍映射到发现，PC 布局保留主页。

## 返回行为

- 分类入口使用现有 `settings-*` 路由。首行返回、移动顶部返回和边缘手势回到分类首页，清理多余分类历史；直接进入子页也可返回首页。
- 移动布局从内容区域左侧 28px 内向右滑动，复用现有方向锁及 64px 阈值；释放后沿用页面返回动效。
- 纵向滚动、短滑、取消、捕获丢失、失焦和 resize 不提交返回。开关、链接、输入框、下拉选择、滑块、单选按钮等控件不发起页面返回。
- 弹层打开时阻止页面手势；触摸隐式捕获从子元素转给滚动容器时，不将子元素冒泡的捕获丢失当作整次手势取消。
- PC 与移动布局切换后仍显示当前分类，并从现有设置存储读回设置值。

## 验证

```powershell
pnpm check
pnpm test
pnpm dev --host 127.0.0.1 --port 5190 --strictPort
# 在另一终端设置 PR9_PLAYWRIGHT_MODULE 为已有 playwright/index.mjs；不自动安装依赖。
# 本机可设置 ZT_BROWSER_CHANNEL=msedge。
node scripts/browser/shared-settings.mjs
```

手势自检见 `settings-back-gesture.test.mjs`。浏览器测试覆盖两种布局与明暗主题、所有分类、首行返回、分类历史清理、直接子页入口、布局切换、设置值保留、音源摘要更新、真实触摸右滑与弹层阻塞。截图和结果保存在未提交的 `browser-artifacts/`。

不在本机构建或打包。Android 真机的系统边缘手势冲突、横竖屏及无障碍体验仍需设备验收；测试数据仅使用隔离浏览器 fixture，不修改用户的实际设置。
