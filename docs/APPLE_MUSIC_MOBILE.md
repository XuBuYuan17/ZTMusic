# Apple Music 移动端播放器实现

## ✅ 已完成

### 布局结构
```
┌─────────────────────────────┐
│  ✕                         │  ← 关闭按钮 (top-left)
│                               │
│         █████████████       │  ← 大封面 (可点击切换歌词)
│         █████████████       │     360px max, 圆角16px
│                               │
│       歌曲名称（24px 粗体）   │  ← 歌曲信息左对齐
│       艺术家（16px 灰色）    │
│                               │
│  ▬▬▬▬●────  1:42 / 3:20  │  ← 进度条 + 时间
│                               │
│  ⏮     ▶     ⏭     ♡  ⎘  │  ← 控制按钮 (64px 播放)
└─────────────────────────────┘
```

### 歌词模式布局
```
┌─────────────────────────────┐
│ ██  歌曲名称（16px 粗体）   │  ← 小封面 (72px) + 歌曲信息
│ ██  艺术家（13px 灰色）    │        右对齐显示
│     正在播放（红色Badge）    │
│                              │
│  歌词行1（半透明灰）        │  ← 全屏歌词滚动
│  歌词行2（半透明灰）        │
│  歌词行3（28px 白色加粗）   │     当前行高亮放大
│  歌词行4（半透明灰）        │
│                              │
│                              │
└─────────────────────────────┘
```

## 🔧 核心特性

| 特性 | 说明 |
|------|------|
| **模式切换** | 点击封面 ↔ 切换正常/歌词模式 |
| **过渡动画** | `cubic-bezier(0.32, 1.25, 0.38, 1)` 弹性效果 |
| **封面飞行** | 两种模式间封面位置平滑过渡 |
| **毛玻璃效果** | (可选) 底部控制栏可添加 backdrop-blur |
| **歌词高亮** | 当前行放大到 28px，前后行半透明 |
| **安全区适配** | `env(safe-area-inset-top/bottom)` |

## 🚀 启用方式

```diff

+ import LyricsPage from './lib/components/LyricsPageV2.svelte';
```

或者临时测试：

```svelte

```
